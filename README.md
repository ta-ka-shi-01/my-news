# My News — v0.2（カテゴリ別表示）

標準ライブラリのみでGoogleニュースの検索RSSを取得し、`news.json`を生成する個人向け試作品です。

## 使い方
1. `python collect.py` を実行。インターネット接続が必要です。
2. `python -m http.server 8000` を実行。
3. ブラウザで `http://localhost:8000` を開きます。
4. `python -m unittest discover -s tests` で基本テストを実行できます。

## GitHub Pagesで公開する場合
リポジトリへファイルをアップロードし、Settings → Pages → Deploy from a branch → main / root を選択。Actionsの書き込み権限も許可してください。スケジュール実行は遅延・停止する場合があります。

## 注意点
- 取得元のRSSの提供状況・利用条件・リンク先の動作は要確認です。
- 現状の「注目」は暫定キーワード判定です。重要度をAIが判定する仕組みではありません。
- 成人向け同人記事は直近14日を対象とし、検索結果に含まれる関連語で絞り込みます。誤判定・見落としがあります。
- RSSがGoogleニュースの中継リンクを返す場合はそのリンクへ移動します。元媒体への直接リンク化は未対応です。
- ニュース一覧には記事本文を転載しません。
- 全取得元が失敗した場合、既存データを上書きしません。一部失敗の場合は一部の記事が欠落する可能性があります。
- Googleニュース検索RSSの網羅性は保証されません。

## v0.2：カテゴリ別の表示
- 「すべて」はゲーム業界 → 成人向け同人ゲーム → 野球の順で表示します。
- 各セクションは公開日時の新しい順に最大5件。「もっと見る」で該当カテゴリの全記事に切り替わります。
- 個別タブではそのカテゴリの全記事を公開日時の新しい順に表示します。
- 記事のカテゴリを色付きラベルで表示します。
- 記事が0件のカテゴリには空状態を表示します。
- 収集処理、検索条件、更新スケジュール、news.json の形式は変更していません。

表示の自動検証：`node tests/test_ui.cjs`（Node.js、追加パッケージ不要）。
収集の既存テスト：`python -m unittest discover -s tests`。
